# 再練一張 · 考卷筆跡清理

依 v1.1 規劃製作的瀏覽器本機工具。流程為：保留原圖 → 校正 → AI 優先 → 半自動調整 → 手動精修 → 確認匯出。AI 結果滿意即可直接匯出，後兩層按需使用。

目前為 **0.4.0 實驗版**，已發布至 [GitHub Pages](https://jyyounz-lab.github.io/exam-cleaner/)，已整合真正的預訓練分割模型，並非把色彩規則稱為 AI。中文兒童考卷品質、iPhone／Android 實機速度仍待驗收；無法保證恢復被手寫完全遮住的題目。

## 執行

需要 Node.js 22.12 以上，建議 Node.js 24 LTS。

```powershell
npm ci
npm run prepare:runtime
npm run dev -- --port 4173
```

開啟 `http://127.0.0.1:4173/`。正式建置與離線測試：

```powershell
npm run build
npm run preview -- --port 4174
```

開啟 `http://127.0.0.1:4174/`。靜態發布使用 `dist/` 全部內容，須以 HTTPS 提供服務；本機 localhost 可使用 HTTP。正式版資源快取完成、頁尾顯示「工具與 AI 已可離線使用」後，才可關閉網路。開發模式不註冊 Service Worker。

## 使用

1. 選擇 JPG／PNG 或拍照，也可使用工具內建的合成示範考卷。
2. 四角對齊考卷，旋轉方向。粗黑原子筆、麥克筆或螢幕手寫可選「粗黑筆跡／螢幕手寫」，會搭配紋理修補；細筆、彩筆、鉛筆使用混合模式。按「完成校正，AI 清除與修復」。
3. AI 完成後自動顯示「清除＋紙張背景修復」成果。可切換遮罩／校正底圖比對，滿意即可確認匯出。
4. 半自動層可調整 AI 門檻、補選紅／藍筆跡及限定處理範圍。框選本身不會擦掉整塊題目。
   系統使用整段筆畫證據補齊無底線作答；細框線、印刷排列與圖案紋理提供保護。粗黑模式以較厚筆畫為候選，減少選到圈內的細印刷字。圈線與題目相交、插圖及筆畫末端仍須人工檢查。框選並啟用黑灰候選可取回後處理未選入的模型候選。
5. 手動層可補擦、還原題目、保留及取消保留；還原可直接在清除預覽使用細筆刷，筆刷最小為圖片寬度的 1/1000。支援復原／重做、100%～800% 縮放、移動與雙指縮放。
   同字取樣修補：按「1. 框選完整的相同字」，從清除預覽（或切到校正底圖）框選相同字形及大小的完整文字，保留少量紙面邊距；確認取樣預覽，再點缺字中心放置。取樣固定為當時的像素快照，後續修改來源不會變更已確認的字。紙色會依目標區調整，邊緣柔化；手動保留區仍優先，之後的補擦／還原可修正這塊內容。
6. 匯出視窗比較清除前後，勾選已檢查，再下載 JPG 或 A4 PDF。
7. 「下載原圖」提供匯入的原始檔案；「儲存進度」保存目前原圖、校正底圖、AI 機率與編輯歷史於此瀏覽器。

## 原圖、隱私與資料

- 原始 `File` 不重新編碼；原圖下載與輸出成果分開。所有清除從未清除的校正底圖與分層遮罩重新合成。
- AI、半自動、手動共用同一個最終遮罩。膨脹之後再次扣除人工保留、排除及 AI 印刷保護區。
- 黑灰筆畫以元件證據、鄰近印刷排列與圖片紋理判斷；局部紙色補正與分開的黑白／色彩連通分析，避免手機陰影與筆跡連成大片。細線檢查避免把粗直筆畫當成框線；邊緣補選使用固定快照，避免逐像素擴散。人工保留與排除區始終優先；手動補擦可更正 AI 的錯誤保護。
- 紙張修復先以局部填補清除，再估計無墨色的紙面背景回填，維持原有亮度與陰影；可選紋理模式。具足夠鄰近證據的直線交疊處，可沿同一印刷線取樣修復。
- 「還原題目」從未清除底圖精確取回誤刪內容。被原始筆跡完全遮住的字形仍無法由單張照片保證復原，須人工確認。
- 清除只作用於最終遮罩內；同字修補只改變人工放置的矩形範圍。人工保留區始終精確保留底圖；JPEG 本身為有損格式，編碼後的像素可能有微小差異。
- 不設圖片上傳 API、雲端 AI、登入資料庫或分析追蹤。執行時下載的只有本站程式、影像引擎與模型。
- AI 模型約 1.13 MiB；完整網站、OpenCV 與 ONNX WASM 約 30 MB，首次離線準備需要連線與儲存空間。
- 圖片限制：35 MB、最多 6400 萬像素。工作與輸出長邊以約 2000 px 為上限；原圖原始資料獨立保留。瀏覽器仍可能在解碼時需要較多記憶體。
- 暫存使用 IndexedDB，可能因空間不足、清除網站資料、瀏覽器策略或換裝置而遺失。請下載重要原圖與成果。匯出的 JPG／PDF 不包含可繼續編輯的遮罩。
- Service Worker 只快取本站的已知程式與模型資源，版本以內容雜湊區分，只清理本工具的舊版快取。原始考卷不放入服務工作者的資源快取。

## 模型與驗證範圍

模型採 [PHTI-WS / printed-hw-segmentation](https://github.com/Jumpst3r/printed-hw-segmentation) 的 MIT 預訓練 FCNN，固定來源 commit，直接讀 H5 權重重建 ONNX。輸出印刷／手寫／背景三類機率，影像清除另由 OpenCV Telea 完成。

- 原始與轉換模型 SHA、預處理與契約：`public/models/metadata.json`。
- 授權：`public/models/PHTI-LICENSE.txt`。
- 轉換方法、私人訓練資料限制與來源範例測試：`research/MODEL-CARD.md`。
- NumPy 等效原架構與 ONNX CPU 最大誤差約 `6.56e-7`；這是轉換等效性，並非考卷清除準確率。
- 作者公開英文範例的指定 crop 已做 smoke test；非獨立中文兒童考卷品質證據。
- Chrome 本機 WASM 已實際執行，示範考卷約 35 tiles、單執行緒約 17 秒；依硬體而異，不保證手機速度。

## 實作選擇與後續

React + TypeScript + Vite、ONNX Runtime Web、OpenCV.js、pdf-lib。單一原生 Canvas 負責四角及遮罩操作，取代規劃中 Cropper／Fabric 的雙 Canvas 組合，以集中座標與遮罩狀態；不額外建立重複編輯狀態。簡單進度儲存採 IndexedDB，暫不加入 OPFS。

0.2.0 加入兩組合成回歸素材，包含乾淨參考圖、獨立筆跡層、印刷層及平坦／陰影紙面。品質檢查分別計算筆跡殘差、印刷受損及遮罩外改動，並與固定的 0.1.0 原始碼比較；這是合成回歸測試，不能視為真實考卷準確率。

0.3.0 新增無底線黑筆、灰色邊緣、粗直筆畫及不同尺寸的回歸案例。亦使用使用者授權的單張本機截圖目視比對：多個原先漏選的作答可清除，但圈線相交處、框線接點與插圖附近仍有殘留或誤選，因此不是可免檢查直接重印的成果。該照片、辨識圖層及輸出僅保存在被 Git 忽略的本機測試目錄，不隨網站或原始碼發布。模型權重未重新訓練；改善來自選取、保護與修補流程，沒有真實考卷辨識率數值。

待續工作：真實中文／注音／數學考卷品質集、手機實機效能、WebGPU、可靠自動紙張外框、進階去陰影、多頁 PDF、可攜式編輯專案備份及瀏覽器儲存容量管理。P0 操作流程可試用，正式品質指標以後續驗收為準。

GitHub Pages 部署設定保存在 `.github/workflows/pages.yml`；`.openai/hosting.json` 保留原 Sites 身分，原私人網站未變更。`public/_headers` 亦提供 Cloudflare Pages 所需的跨來源隔離與 CSP 設定。WASM 基線為單執行緒，不依賴 WebGPU 或跨來源隔離才能運作。

0.3.0 品質回歸與 0.4.0 瀏覽器驗證報告保存在 `docs/`；合成案例可比較程式回歸，真實影像仍須逐張檢查。使用者原圖與其修正成果只保存在本機忽略目錄。

## 0.4.0 文字修補範圍

此版新增人工確認的同字取樣，並改善成果畫面的細筆刷操作。AI 模型與 0.3.0 清除策略保持一致；不是 OCR 重排或自動補字。沒有清楚同字、字體大小不同、完整遮擋的內容仍需人工確認。取樣會包含選框中的內容，應避開圈線；大範圍陰影或圖案的紙色銜接仍可能可見。

0.4.0 已發布至 GitHub Pages。使用者已明確同意公開本專案原始碼與 Git 歷史；原 Sites 私人網站維持 0.2.0。
