# 中文／注音鉛筆模型 v1

0.7.0 新增可選的「中文／注音鉛筆（新模型・實驗）」，預設門檻 96%、紋理修補。模型於 2026-11-10 完成訓練，runtime revision 為 3。96% 是選取門檻，不是辨識準確率。原英文課本仍使用 revision 2；PHTI FCNN 權重不變。

## 資料與訓練

新增六組同頁作答照片與真正空白原稿，合併先前十組英文課本的稀疏弱標註。舊比較圖由其他工具清理，包含缺字與殘影，沒有當成完整乾淨真值。新增空白照片也有背面透印、拍攝光線和透視差異。

- 共 16 個來源頁，按頁分為 11 頁訓練、2 頁驗證、3 頁開發評估。同頁作答、空白及所有尺寸變體維持同一分割。
- 新作答頁為 1108 像素寬，另做 900／1500 寬變體；空白頁保留原生尺寸並加入相同目標寬度。與舊資料合計 66 個影像版本，並非 66 張獨立頁面。
- 作答與空白先以 SIFT／RANSAC 對齊，再用平滑的印刷特徵殘差補正。只在可信錨點凸包內產生配對標籤；排除不確定交疊及頁緣。手寫標註使用經檢視的局部區域，並未完整標註整頁。
- 使用 37 個特徵：27 個連通元件形狀、顏色、FCNN 與周邊資訊，加上 10 個局部像素及鄰域特徵。這讓同一元件內的深色印刷與淡手寫可以分別判斷。
- 實際訓練 160 棵 histogram gradient boosting 樹，深度最多 5、每樹最多 24 葉、learning rate 0.08、min samples leaf 30、L2 1、seed 20261109，按來源頁／類別平衡權重。
- 訓練取樣共 183,566 像素，其中手寫 50,999；含 24,567 個「接觸手寫的印刷內容」額外負樣本。額外取樣僅來自訓練頁，每變體最多 1,600 個，權重 4。使用者確認的舊英文原印示範仍作保留證據。
- JSON 匯出與 Python sklearn 在所有取樣資料上的機率最大差異為 0。模型約 209 KiB，特徵資料 SHA-256、模型 SHA-256 與參數見 `public/models/zhuyin-metadata.json`。

本輪比較六種候選：原元件模型的 120 棵深度 3、160 棵深度 4、頁面平衡版本、亮度拆分加父元件資訊、局部像素模型、加入接觸印刷負樣本的局部像素模型。統一替換模型會影響舊英文示範內容，因此最後採用獨立中文模式。

## 效果與限制

以舊英文課本模型 90% 與新中文模式 96% 的最終遮罩比較，六張新作答頁在原尺寸的稀疏標註區域中，均選中更多手寫且更少保留內容。18 個作答尺寸版本有 17 個手寫選取增加、全部保留內容誤選下降。

例外為開發評估頁 zh45 的 1500 寬版本：手寫選取 4,542 → 4,016，保留內容誤選 590 → 111；保護較保守而漏擦增加。該頁原尺寸的已標註手寫選取僅 3,754 / 13,892，圈線與連線仍有明顯殘留。這個限制不能由彙整改善掩蓋。

全部 36 個中文作答／空白版本的已標註保留墨色誤選比例低於 0.5%，仍非零；分母不是整頁像素。30 個舊英文版本繼續使用原模式，遮罩與改版前逐位元一致。開發評估頁已被檢視並用於選型，**不是獨立盲測**；單一教材的六頁也不足以宣稱泛化至所有中文、數學或黑筆考卷。

修補沿用鄰近紙張紋理、具足夠證據的導線修復及人工同字取樣。這輪沒有訓練生成式補字模型，也沒有把空白照片直接貼入使用者成果。深色圈線、虛線格、反面透印、與印刷交疊的筆畫仍需半自動補清除／人工還原。沒有驗證手機實機速度或證明新版分析更快。

## 本機重現

資料、標註及成果保存在 Git 忽略的 `test-results/`，不隨網站發布。需先準備經核對、按來源頁分割的私人 dataset。`manifest.json` 的 `pairs` 每筆包含 `id`、`directory`、`sourcePage`、`split`；`directory` 指向含 `meta.json`、`rgba`、`hand`、`print`、`binary`、`labels`、`verified`、`original.png` 的資料目錄。沿用既有研究腳本產生底層機率與尺寸變體；標籤 0 為保留、1 為手寫、255 為未標註。確定原印內容在 `verified` 使用 0。

```powershell
node --experimental-strip-types research/extract_pixel_features.mjs PRIVATE_COMBINED PRIVATE_PIXEL_OUTPUT
test-results/training-env/Scripts/python research/train_pixels.py PRIVATE_PIXEL_OUTPUT
# 啟動 npm run dev -- --port 4175 後，驗證已選定的正式模型：
node research/render_zhuyin.mjs PRIVATE_COMBINED
```

Python 依賴沿用 `research/training-requirements.txt`。抽樣及訓練腳本只寫入指定的私人輸出資料夾。候選經檢視後，另設定發布 revision、來源說明、限制及門檻，再更新 public 模型與 metadata 雜湊；腳本不會直接替換網站模型。正式驗證指標與操作測試記錄見 `docs/v0.7.0-validation.json`。
